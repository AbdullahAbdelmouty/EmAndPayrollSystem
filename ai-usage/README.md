# Transparency and Judgment in AI Usage

As part of modern software development, AI tools were utilized during the development of this application to assist with initial setup, file structuring, and code generation. Below is a detailed breakdown of the AI usage, in accordance with the assessment's guidelines.

## AI Tools Used

- **Claude Chat**: Utilized primarily for assistance with defining the initial **file structure** and developing the **backend API**. Claude helped outline the architectural approach and implement boilerplate logic for the backend routes, controllers, and services.
- **Codex**: Utilized for assistance with **frontend development**. Codex provided inline code suggestions, helping to accelerate the creation of React components, styling, and integration with the backend endpoints.

## Judgment and Review

While AI tools were instrumental in speeding up the development process, all AI-generated code was rigorously reviewed and refined:

1. **Full Comprehension**: Every line of code incorporated into the final repository has been reviewed, understood, and manually tested. I can confidently explain the rationale behind the architectural choices, algorithms, and logic implemented throughout the application.
2. **Refinement and Adaptation**: AI-generated code was not accepted blindly. It was adapted to meet the specific requirements of the assignment, ensuring proper input validation, consistent error handling (RFC 7807), and adherence to SOLID principles.
3. **Security and Quality Control**: Manual review was conducted to ensure no sensitive information or secrets were included, proper business rules (like the payroll calculation) were accurately implemented, and code quality remained high.
